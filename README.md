# EVLZSH 👾

**Your terminal. Your environment.**

EVLZSH is a modular Termux environment installer designed
to recreate a carefully configured Zsh environment safely.

## Project status

🚧 Early development. Installation functionality is not
yet ready for general use.

## Goals

- Complete Termux environment installation
- Modular configuration and tooling
- Download-based asset distribution
- Version-pinned third-party dependencies
- SHA-256 download verification
- Automatic safety backups
- Repeatable, recoverable installation
- No silent overwrites
- No unnecessary root requirements

## Default profile

Complete.

## Installer

Written in Bash for compatibility with fresh Termux
installations where Zsh may not yet be installed.
